# Dataset attribution

**Power Consumption of Tetouan City**

Creators: Abdulwahed Salam and Abdelaaziz El Hibaoui.

Citation: Salam, A. & El Hibaoui, A. (2018). *Power Consumption of Tetouan City* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5B034.

- [Official dataset page](https://archive.ics.uci.edu/dataset/849/power+consumption+of+tetouan+city)
- [Creative Commons Attribution 4.0 International licence](https://creativecommons.org/licenses/by/4.0/)

The included file is named `Tetuan_City_power_consumption.csv`; the catalogue file uses spaces in its filename. The project keeps this raw input separate from processed outputs. Cleaning and feature transformations are documented in Notebooks 01 and 04; the derived files are in `outputs/processed/` and retain this source attribution.

The checked local CSV contains 52,416 data rows from 1 January through 30 December 2017 at ten-minute intervals. The catalogue displays 52,417 instances. The project uses the observed file contents and does not insert an unobserved 31 December.

The UCI variables table does not specify measurement units or timezone. Interpretations should retain that limitation rather than inventing metadata.
